# VIH Metaverse Spaces — Product FAQ

## Overview

This document is synthetic test data created for the VIH VoiceRAG pilot.

VIH Metaverse Spaces is our platform for persistent, shared 3D workspaces used for training, events and collaboration.

## Capacity

A single Space supports up to 250 concurrent avatars. Events larger than 250 attendees use broadcast mode, which supports up to 5,000 view-only participants.

## Supported devices

Spaces runs on Meta Quest 3, Apple Vision Pro, and PC VR headsets through OpenXR. The web client requires a browser with WebGPU support.

## Data and security

World state is saved automatically every 30 seconds. Enterprise customers can use single sign-on through SAML 2.0.

Customer data can be hosted in three regions: India (Mumbai), the European Union (Frankfurt) and the United States (Oregon).
